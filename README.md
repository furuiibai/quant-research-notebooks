# quant-research-notebooks
Personal quantitative finance research & CQF practice implementations.

This repo contains notebooks and Python scripts for quantitative finance study, including option pricing, Monte Carlo simulation, volatility modelling and portfolio optimization.

## 📁 Repository Structure

quant-research-notebooks/
├── options/          # Option pricing, Black-Scholes, Greeks, binomial tree
├── monte_carlo/      # Monte Carlo simulations for derivatives
├── portfolio/        # Portfolio construction, optimization & risk metrics
├── timeseries/       # Return analysis, volatility, GARCH models
├── utils/            # Reusable helper functions
└── data/             # Local raw datasets (gitignored)

## 🧪 Environment
Python 3.10+
Core dependencies: `numpy`, `pandas`, `scipy`, `matplotlib`, `scikit-learn`

> Note: Private research repo, for self-study & CQF practice only.
